💰 SaveIQ – AI-Powered Savings Goal Tracker

SaveIQ is an AI-powered personal finance management application designed to help users manage their savings goals, monitor financial progress, and make smarter saving decisions.

The platform helps users set financial targets, track their savings journey, receive intelligent AI-based recommendations, and stay on track with automated deadline alerts.
⭐⭐⭐Demo Video Link: https://drive.google.com/file/d/1n30qhcNhD-c0f3ZI-QVHb2dNTDd38qR6/view?usp=drivesdk 

🚀 Key Features

- 🎯 Savings Goal Management: Create and manage personal savings goals.
- 📊 Progress Tracking: Monitor savings progress through visual representations.
- 🤖 AI-Powered Recommendations: Get intelligent suggestions to improve saving habits.
- ⏰ Deadline Alerts: Receive automated reminders about upcoming goal deadlines.
- 💡 Smart Financial Planning: Make better saving decisions with AI assistance.
- 📈 Progress Visualization: Understand financial progress using charts and dashboards.

⚙️ Installation & Setup

Follow these steps to run SaveIQ locally.

1. Clone the repository

git clone https://github.com/abhishekwaghmare97625-wq/saveiq-ai-savings-goal-tracker.git

2. Navigate to the project folder

cd saveiq-ai-savings-goal-tracker

3. Install dependencies

bun install

4. Configure environment variables

Create a ".env" file using the provided ".env.example" file and add the required API credentials.

5. Start the development server

bun run dev

6. Open the application

Open the local URL displayed in your terminal.
